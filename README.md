# 🎟️ EventHub & Ticket Booking Dashboard

A modern, responsive full-stack **Event Booking Platform and Management Dashboard** built for organizing events, tracking seat capacities, and managing ticket sales in real-time.

## ✨ Key Features

- **📊 Real-Time Analytics Dashboard:** Automatically calculates total revenue, ticket sales volume, active events, and dynamic seat occupancy percentages.
- **🛠️ Full CRUD Operations:** Create new events, update details, view rich specifications, and delete events seamlessly.
- **🎟️ Instant Ticket Booking:** Reserve seats with immediate capacity validation and automatic status updates (e.g., switches to *Sold Out* when full).
- **📅 Interactive Schedule & Calendar:** Month-by-month grid layout tracking upcoming event deadlines and schedules.
- **👥 User & Attendee Management:** Switch between user profiles and manage registered attendees.
- **📝 Activity Logs & Persistence:** Local storage synchronization with a live event activity stream.
